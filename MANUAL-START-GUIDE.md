# 🚀 Manual Start Guide - GUARANTEED TO WORK

## Step 1: Start Your App
Open terminal in this directory and run:
```bash
npm start
```

If that doesn't work, try:
```bash
yarn start
```

## Step 2: Open in Pi Browser Mobile
Once the app starts, open this URL in Pi Browser mobile:
```
https://flappypi6856.pinet.com/test
```

## Step 3: Use Console Log Copy Button
1. Click "🚀 Start Test & Capture Logs" button
2. Wait for the test to complete
3. Click "📋 Copy Logs" button
4. Paste the logs somewhere to see what's happening

## What the Console Log Copy Button Does:
- ✅ Captures all console logs automatically
- ✅ Tests payment creation
- ✅ Shows exactly what's happening
- ✅ Copies all logs to clipboard
- ✅ Helps debug payment issues

## If Still Not Working:
The console logs will show you exactly what's wrong:
- Pi SDK not available
- Network issues
- API problems
- Configuration issues
