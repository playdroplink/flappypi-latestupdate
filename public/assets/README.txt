 Flappy Pi Game Assets Structure
================================

Upload your custom images to the following folders:

1. backgrounds/
   - Example: sky_day.png, sky_night.png, clouds1.png, clouds2.png

2. pipes/
   - Example: pipe_green.png, pipe_red.png, pipe_gold.png

3. ground/
   - Example: ground_grass.png, ground_sand.png

4. buttons/
   - Example: play_button.png, shop_button.png, jump_button.png

---

- Use PNG or SVG for best quality.
- Keep file names lowercase and use underscores or dashes.
- After uploading, let the developer know which file to use for each game element.
