# Flappy Pi Pitch Deck

## 1. Introduction
Flappy Pi is a next-generation Flappy Bird-style game with deep integration into the Pi Network blockchain. It combines addictive gameplay with real cryptocurrency rewards, seamless Pi authentication, and a robust in-game economy.

---

## 2. Problem Statement
- **Lack of real-world value in casual games**
- **Fragmented blockchain gaming experiences**
- **Complex onboarding for crypto newcomers**

---

## 3. Solution: Flappy Pi
- **Seamless Pi Network Authentication**: One-click login with Pi credentials
- **App-to-User (A2U) Payments**: Real Pi coin rewards and purchases
- **Ad Network Integration**: Earn Pi by watching ads
- **Cloud Persistence**: Inventory and progress synced via Supabase
- **User-Friendly Onboarding**: No crypto knowledge required

---

## 4. Product Features
- Addictive Flappy Bird gameplay
- Pi Network OAuth login
- In-game shop with Pi payments
- Subscriptions and inventory system
- Pi Ad Network (interstitials, rewarded ads)
- Secure, scalable backend (Node.js + Express)
- Modern frontend (Vite + React + TypeScript)

---

## 5. Architecture Overview
- **Frontend**: Vite + React + TypeScript
- **Backend**: Node.js + Express
- **Blockchain**: Pi Network (mainnet)
- **Database**: Supabase (Postgres)
- **Cloud**: Vercel (serverless)

---


## 6. Pi Network Integration
- **Authentication**: Pi OAuth, secure user data (supports sandbox mode for development/testing)
- **Payments**: 3-step A2U flow (create, submit, complete)
- **Ad Network**: Pi Ad SDK for monetization
