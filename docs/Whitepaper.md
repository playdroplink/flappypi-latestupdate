## 1. Introduction
Flappy Pi is a next-generation play-to-earn mobile game built for the Pi Network ecosystem. Inspired by the classic Flappy Bird, it combines addictive gameplay with real crypto rewards, NFTs, and social competition. Our mission is to bring fun, fairness, and financial empowerment to millions of Pi users worldwide.

## 2. Vision & Mission
We envision a world where anyone can earn real value by playing skill-based games. Flappy Pi aims to be the flagship game of the Pi Network, pioneering fair play, transparent rewards, and a vibrant player-driven economy.

## 3. Gameplay Overview
* Classic, Endless, and Challenge modes
* Earn Pi and Flappy Coins by achieving high scores and completing missions
* Unlock and collect rare Flappy skins (future NFTs)
* Compete on global leaderboards and tournaments
* Invite friends and earn referral rewards

## 4. Tokenomics
* **Pi:** The only blockchain currency used in Flappy Pi. All smart contracts and transactions are exclusively on the Pi Network blockchain. No other chains will be supported.
* **Flappy Coins:** In-game currency earned by playing, used for upgrades, skins, and power-ups. **Flappy Coins (FC) cannot be converted to Pi at this time and are only usable for in-game assets. If and when Pi Network supports smart contracts, a conversion mechanism may be considered in the future, subject to Pi Network's Mainnet policies.**
* **NFTs:** Unique Flappy skins and collectibles, to be issued as Pi Network NFTs when smart contracts are available.

## 5. Pi Network Integration
* All blockchain features, smart contracts, and NFTs will be deployed exclusively on the Pi Network mainnet as soon as available.
* No support for any other blockchain or cross-chain features—Flappy Pi is Pi Network only.
* Seamless Pi authentication and wallet integration
* All rewards and payments are processed via the official Pi SDK
* Strict anti-cheat and fair play mechanisms

## 6. Roadmap
