# Flappy Pi

**Flappy Pi** ist ein süchtig machendes Flappy Bird-ähnliches Spiel mit endlosen Levels, vollständig integriert in das Pi Network-Ökosystem. Spieler können sich mit Pi anmelden, In-Game-Käufe mit Pi-Münzen tätigen, an einer Echtzeit-Rangliste teilnehmen und wöchentliche Pi-Belohnungen gewinnen.

---

## Funktionen

- Endloses Side-Scrolling-Gameplay mit prozedural generierten Rohren
- Sanfte Tap/Klick-Steuerung mit steigender Schwierigkeit
- Anpassbare Vogel-Skins, kaufbar über Pi-Zahlungen
- Pi Network-Anmeldung und Wallet-Integration
- Echtzeit-Rangliste mit den 10 besten Spieler-Scores
- Wöchentliche Pi-Token-Belohnungen für Ranglisten-Gewinner
- Belohnte Werbung für Wiederbelebungen und kleine Pi-Boni
- Responsives Design für Desktop- und Mobilgeräte
- Marken-Splash-Screen und Logo von mrwain organization

## Installation & Setup

### Voraussetzungen

- Node.js (v14 oder höher)
- npm oder yarn
- Pi Network Developer-Anmeldedaten
- Firebase oder Ihre bevorzugte Backend-Konfiguration

### Repository klonen

```bash
git clone https://github.com/yourusername/flappy-pi.git
cd flappy-pi
```

### Abhängigkeiten installieren

```bash
npm install
```

### Umgebungsvariablen konfigurieren

Erstellen Sie eine `.env`-Datei im Root-Verzeichnis mit:

```env
PI_APP_ID=ihre_pi_app_id
DATABASE_URL=ihre_datenbank_verbindungszeichenkette
PI_WALLET_ADDRESS=ihre_pi_wallet_adresse
```

### Lokal ausführen

```bash
npm run start
```

## Verwendung

* Melden Sie sich mit Ihrem Pi Network-Konto an
* Spielen Sie durch Tippen oder Klicken, um den Vogel flattern zu lassen
* Kaufen Sie Vogel-Skins, Wiederbelebungen und Multiplikatoren im Shop mit Pi-Münzen
* Überprüfen Sie Ihren Rang in der Rangliste nach jedem Spiel
* Schauen Sie sich belohnte Werbung an, um zusätzliche Leben oder Pi-Boni zu gewinnen
* Wöchentliche Top-Spieler erhalten automatisch Pi-Belohnungen
